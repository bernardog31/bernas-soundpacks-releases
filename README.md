# Bernas Soundpacks

Repositório público de distribuição dos ZIPs da aplicação Bernas Soundpacks.

Os ficheiros são publicados como assets de GitHub Releases. O catálogo, versões e acesso administrativo são geridos pela aplicação e pelo Supabase.

Instalação manual no FiveM. Respeita as regras do servidor e as instruções incluídas em cada ZIP. Nenhuma licença genérica é concedida a conteúdos de terceiros.
